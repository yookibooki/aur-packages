Keeps every package in `packages/*/PKGBUILD` current on the AUR. Nothing else
belongs here.

Adding a package is dropping in one PKGBUILD — no other file changes:

- `packages/<pkg>/PKGBUILD` with `_realver` (the upstream version verbatim),
  `pkgver="${_realver//[-+]/_}"`, `pkgrel`, one `source_<arch>` /
  `sha256sums_<arch>` pair per architecture, and `url=` pointing at the
  package's `github.com/<owner>/<repo>` page — the updater derives the repo
  and every download URL from it. `_allow_prerelease=1` opts into prereleases.
- `.SRCINFO` is generated by `makepkg --printsrcinfo` at publish time and
  pushed to the AUR only; it is never tracked in this repo.

- Checksums come only from downloads. Never `SKIP`, never typed.
- `.SRCINFO` comes only from `makepkg --printsrcinfo`, never hand-edited.
- No comments, no docstrings: the maintainer never reads the source, agents read
  this file.
- Keep it this small — no second script, no second workflow, no PR bot, no merge
  step, no alerting.
- Nothing runs on the maintainer's machine. Prove a change with a run on a
  branch, not locally.
- Secrets: `AUR_SSH_KEY` and `AUR_KNOWN_HOSTS` (`ssh-keyscan -t ed25519
  aur.archlinux.org`, checked against the fingerprint Arch publishes).
