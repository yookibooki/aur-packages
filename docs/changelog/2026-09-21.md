  bearer. **Consequence: the b.ai key must be set as repo secret
  `OPENAI_API_KEY` (`gh secret set OPENAI_API_KEY`).** `BAI_API_KEY` was
  proven to be a no-op (engine.env secrets appear nowhere in the
  compiled lock except as a literal string in models.json) and is kept
  until the route is proven green, then deletable. Threat detection
  stays off; sandbox stays off (maintainer decisions, reasons corrected

  was false).
