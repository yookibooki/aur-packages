# Changelog (2026-09-15)

One file per day: `docs/changelog/2026-09-15.md`,
`docs/changelog/2026-09-16.md`, and so on. A run appends its entries to
today's file (create it if absent) and never edits prior days' files.
Entries carry no date prefix — the filename is the date. Old files are
never pruned; a day of work is small by construction.

- Added growth caps for long-lived files (maintainer decision — autonomous
  runs must not grow files unbounded over years): STATE.md heartbeat log
  capped at 50 entries, closed questions at 5, oldest rotated to
  `docs/archive/`. Changelog split by day (this directory). Also fixed four
  dangling references to `docs/legacy-workflows/` (never created; deletion
  of the old workflows was intentional) to point to git history. Reason:
  files every run reads must stay small forever, and docs must not reference
  directories that do not exist.
- Restructured AGENTS.md. Added "Trust" (strangers install these; never
  commit SKIP; re-cuts halt), "What you can do" (nothing is fenced off;
  discipline is the test), and "This file" (the constitution is revised
  deliberately, with a changelog entry, never as a side effect). Split the
  old "How to be" so machinery (rebuild freely) is distinguished from the
  release path, credentials, and this file (change deliberately). Split the
  old "How to stop" into two flavors of halt: can't verify vs. not mine to
  decide. Substrate moved after Memory. Reason: prior draft said "assume
  nothing here is well designed" without distinguishing constitution from
  scaffolding, and licensed bold rewriting of everything — including the
  release path. Both are now fenced explicitly.
- Added Substrate to AGENTS.md (heartbeat against the 60-day cron kill;
  rebuild-a-runner fallback), and the per-run heartbeat ritual. Reason: a
  quiet repo is a dead repo, and the next run must inherit status, not
  rediscover it.
